# Bilder

In diesen Ordner gehören alle Fotos der Website.
Die Dateinamen müssen exakt mit den Angaben in `src/data/content.ts` übereinstimmen.

## Benötigte Dateien

| Datei | Motiv | Format |
| --- | --- | --- |
| `hero.jpg` | Großes Titelbild, Britta & Lutz | quer, ca. 2400 px breit |
| `damals.jpg` | Paarfoto von damals | 4:3 |
| `heute.jpg` | Aktuelles Paarfoto, **gleicher Bildausschnitt wie `damals.jpg`** | 4:3 |
| `qr-gaestewand.png` | QR-Code zur Gästewand | quadratisch |
| `og-image.jpg` | Vorschaubild für WhatsApp & Co. | 1200 × 630 px |

## Hinweise

* Solange eine Datei fehlt, zeigt die Website automatisch eine gestaltete
  Platzhalterfläche. Es erscheint **kein** kaputtes Bildsymbol.
* Fotos, die Gäste hochladen, landen **nicht** hier, sondern auf dem Webspace
  im Ordner `uploads/bilder/`.
* Empfohlene Größe: längste Kante ca. 1600 px, Qualität ca. 80, unter 300 KB.
* Das Titelbild darf größer sein (bis ca. 500 KB).
* Bitte darauf achten, dass abgebildete Personen mit der Veröffentlichung
  einverstanden sind.
