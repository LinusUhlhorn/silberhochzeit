# Schriften

Die Schriften werden selbst gehostet und **nicht** von Google Fonts geladen.
Dadurch entsteht keine Verbindung zu Servern Dritter – es werden also keine
IP-Adressen der Besucher an Google übertragen.

## Enthaltene Dateien

| Datei | Schrift | Verwendung |
| --- | --- | --- |
| `inter-latin-400-normal.woff2` | Inter Regular | Fließtext |
| `inter-latin-500-normal.woff2` | Inter Medium | Labels, Buttons |
| `cormorant-garamond-latin-300-normal.woff2` | Cormorant Garamond Light | große Namen im Titelbereich |
| `cormorant-garamond-latin-400-normal.woff2` | Cormorant Garamond Regular | Überschriften |
| `cormorant-garamond-latin-500-normal.woff2` | Cormorant Garamond Medium | kleinere Überschriften |

## Lizenz

Beide Schriftfamilien stehen unter der **SIL Open Font License 1.1** und dürfen
frei verwendet und weitergegeben werden.

* Inter – https://github.com/rsms/inter
* Cormorant Garamond – https://github.com/CatharsisFonts/Cormorant

Die Dateien stammen aus den npm-Paketen `@fontsource/inter` und
`@fontsource/cormorant-garamond`.

Fehlen die Dateien, greift automatisch eine Ersatzschrift (Georgia bzw. die
System-Schrift). Die Website funktioniert dann weiterhin, sieht aber nicht
wie vorgesehen aus.
